Loophole — это полностью открытый редактор кода на основе ИИ, созданный на основе Void Editor (который, в свою очередь, является форком VS Code). Он интегрирует возможности ИИ на самом глубоком уровне редактора — не как плагин, а как фундаментальную часть опыта редактирования. Весь ваш код остаётся на вашем компьютере.

Запросы ИИ отправляются **напрямую с вашего компьютера выбранному вами поставщику**. Ваш код никогда не проходит через сервер Loophole. Вы используете свой собственный ключ API или запускаете локальные модели, а Loophole справляется со всем остальным.

Он поставляется с полным движком агентов, встроенным автодополнением, чатом ИИ в четырех режимах, быстрым редактированием, сообщениями о коммитах Git, созданными ИИ, голосовым вводом, отслеживанием использования токенов и затрат, поддержкой серверов MCP, а также поддержкой моделей рассуждений для Claude и OpenAI o1/o3-mini.

## Почему Loophole

- **Приватность через архитектуру, а не политику.** Каждый запрос ИИ отправляется напрямую с вашего компьютера поставщику через его открытый API. Нет бэкенда Loophole, нет логирования подсказок и нет посредников.
- **Четыре режима чата для четырёх типов работы.** Нормальный режим отвечает на вопросы беседой. Режим сбора позволяет ИИ читать и искать в вашей кодовой базе без изменения файлов. Режим планирования позволяет ИИ составить видимый многоэтапный план перед выполнением редактирования. Режим применения превращает простое текстовое описание в готовый к git код за один шаг.
- **Настоящая поверхность инструментов агента.** Агент может читать файлы с разбивкой на страницы, выполнять хирургические редактирования SEARCH/REPLACE, переписывать целые файлы, создавать и удалять файлы и папки, переименовывать и перемещать пути, выполнять команды shell и вызывать инструменты MCP.
- **Параллельные под-агенты.** Агент может порождать под-агенты `general` (полные инструменты) или `researcher` (только для чтения) для обработки независимых подзадач одновременно. Под-агенты могут работать в фоне, пока вы продолжаете редактирование.
- **Автодополнение, разработанное для скорости.** Встроенный механизм заполнения использует подход Fill-In-the-Middle, отправляя код перед и после курсора, чтобы модель точно предсказала, что должно быть между ними. Без потерь токенов, без задержек.
- **Назначение модели для каждой функции.** Чат, быстрое редактирование (Ctrl+K), автодополнение, применение и генерация сообщений о коммитах Git каждый имеют свой собственный слот модели. Используйте мощную модель рассуждения для чата и быструю модель для автодополнения.
- **20+ поставщиков, включая полностью локальные.** Anthropic, OpenAI, Google Gemini, DeepSeek, xAI, Mistral, Groq, Cohere, Perplexity, OpenRouter, Together AI, Fireworks AI, Inception Labs, LiteLLM, Vertex AI, Azure OpenAI, AWS Bedrock, Ollama, vLLM, LM Studio и совместимые с OpenAI точки доступа.
- **Поддержка моделей рассуждений.** Когда модель поддерживает расширенное мышление, Loophole настраивает её правильно: ползунки бюджета для рассуждения в стиле Anthropic, ползунки усилий для стиля OpenAI и совместный интерфейс, чтобы вы видели как мышление, так и результат.
- **Поддержка серверов MCP.** Подключите внешние серверы Model Context Protocol для расширения агента с помощью пользовательских инструментов. Инструменты MCP отображаются рядом со встроенными инструментами в режиме агента и проходят через те же шлюзы утверждения.
- **Отслеживание использования токенов и затрат.** Каждый ответ записывает входные токены, выходные токены и ориентировочную стоимость в USD на основе ценообразования каждого поставщика. Диалог использования токенов показывает совокупные суточные итоги и разбивку по поставщикам.
- **Сообщения о коммитах ИИ.** Панель Git SCM имеет кнопку ИИ, которая отправляет ваш поэтапный diff в настроенную модель SCM и передаёт сообщение о коммите прямо в поле ввода Git. Это интегрировано с Git, поэтому вы можете изменять и делать push из Loophole.
- **Голосовой ввод.** Вы можете диктовать сообщения в чат, используя микрофон. Loophole захватывает аудио PCM, транскрибирует его через поставщика и заполняет ввод чата результатом.
- **Элементы управления утверждением.** Редактирование файлов, команды терминала и вызовы инструментов MCP каждый имеют свою категорию утверждения. Вы можете требовать ручного подтверждения для каждой категории или включить автоматическое утверждение глобально для доверенных операций.

## Сборка из исходного кода

Требования: Node.js 22 или выше, Python и инструменты сборки C++.

```bash
git clone https://github.com/loophole-ai/loophole-ide.git
cd loophole-ide

npm install
npm run buildreact

# В одном терминале
npm run watch

# В другом терминале
npm run electron
```

## Структура проекта

Весь код, специфичный для ИИ, находится в `src/vs/workbench/contrib/void/`. Слой `browser/` содержит механизм автодополнения, сервис сбора контекста, интеграцию SCM, панели боковой панели и быстрого редактирования, а также интерфейс чата. Слой `common/` определяет общие типы и константы. Слой `electron/` обрабатывает интеграцию Electron и интеграцию системы.

Каталог `extensions/` содержит все стандартные встроенные расширения VS Code плюс `theme-loophole`, пользовательскую тёмную тему Loophole. Каталог `cli/` содержит инструменты CLI на основе Rust. Скрипты сборки и конфигурация упаковки находятся в корне.

## Как текут запросы ИИ

Действие пользователя — отправка сообщения чата, нажатие Ctrl+K или ввод в редактор — запускает соответствующий сервис. Этот сервис вызывает `contextGatheringService` для сбора контекста из открытых файлов, текущего выделения, истории git и активного терминала. Собранный контекст отправляется агенту, который выполняет многоэтапный цикл агента. Действия агента (редактирование, создание файла, команды shell, вызовы инструментов MCP) направляются обратно в редактор для выполнения или утверждения.
